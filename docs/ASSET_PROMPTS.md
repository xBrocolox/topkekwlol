The game is fully playable with its built-in procedural art. Any PNG you drop into `assets/ai/` **with the exact filename below** replaces the procedural version. After adding files run `node tools/make_manifest.mjs`.

**Tips**
- Sprites (`battle_*`, `enemy_*`): ask for a *flat solid magenta background*; the engine removes it automatically (or supply a transparent PNG).
- Keep one consistent art style across all pieces: reuse the style line at the end of every prompt.
- Portraits are cropped square (cover); backdrops are cropped to 16:9.
